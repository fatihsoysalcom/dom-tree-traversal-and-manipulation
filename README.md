# DOM Tree Traversal And Manipulation

This example demonstrates how JavaScript interacts with the browser's Document Object Model (DOM). It shows how to select elements, traverse the DOM tree, and dynamically modify the page's content and styles by adding text, changing classes, and hiding elements.

## Language

`javascript`

## How to Run

Open the `index.html` file in any web browser. Click the buttons to see the DOM manipulation in action.
